Cost per request

A standalone embed of the coding agent page's cost-per-request charts for a recorded coding agent session — cached at the bottom, then input and output.

The element automatically follows your browser's light or dark color scheme; the session attribute picks the recorded session (defaulting to coding-agent), and the variant attribute switches between the two charts: per-request (the default) shows what each provider request cost, cumulative the session's running total after each request.
